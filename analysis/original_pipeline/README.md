# Original pipeline (provenance)

These are the scripts that produced the tables, figures and evidence ledger of the paper in the original environment: `phase11b_extract.py` (extraction of the 40 cell records), `evidence.py` (resolution of every manuscript number into the evidence ledger), `generate_all_tables.py`, `generate_all_figures.py` and `generate_intro_figure.py`. They contain the absolute paths of that environment and are kept unchanged for provenance. To verify the numbers from this repository, use `analysis/reproduce.py`, which uses repository-relative paths only.
